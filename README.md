# JBrowse
A free, opensource Android (other Versions are planned) browser with an minimalistic Design, but colorfull!.
Based on Mozilla‘s Gecko Engine.
Please notice, that this App is not and will not be available on the Google Play store. So you have to sideload it.
But Google want‘s to lock android down, so you have to do many steps to sideload apps. 
Please support me and the whole Community around opensource-android-Apps and visit this side: keepandroidopen.org
This update is not an OS update but an google-play-services-update. This Updates don‘t need any agreement and you cant stop it.
But: If you use an VM like Waydroid, you can use install it, if you don‘t install thise services. Same for Custom-Roms like Lineage OS or Graphene OS!
